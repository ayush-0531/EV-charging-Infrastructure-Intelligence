🔋 EV Charging Infrastructure Analytics

**📌 Overview**

This project analyzes an EV charging infrastructure dataset to understand the distribution, capacity, operators, connector types, and usage patterns of charging stations.

The analysis focuses on identifying geographical infrastructure gaps, charging-capacity opportunities, operator concentration, and connector-type trends that can help EV charging businesses make more data-driven decisions about network expansion and infrastructure upgrades.

The project follows an end-to-end data analytics workflow using Python, SQL, and Power BI, starting from data cleaning and exploratory analysis and ending with an interactive business intelligence dashboard.

**🎯 Objective**

The main objective of this project is to evaluate the current EV charging infrastructure and answer key business questions such as:

Where are EV charging stations concentrated?
Which cities and states have relatively limited charging infrastructure?
Which locations have the highest and lowest total installed charging capacity?
Which charging operators have the largest network presence?
How concentrated are operators across different regions?
Which connector types are most commonly deployed?
How does charging capacity vary across connector types and operators?
Which locations could represent opportunities for new station deployment or capacity upgrades?
